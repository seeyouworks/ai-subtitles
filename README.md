# AI Subtitles

개인용 Windows 프로그램입니다. 영상이나 원문 SRT를 선택하면 **입력 파일과 같은 폴더**에 자막을 저장합니다. 음성 인식은 로컬 faster-whisper, 번역은 로그인한 Codex CLI를 사용합니다.

## 저장소 받기

Python 3.10 이상(Tcl/Tk 포함)과 ChatGPT 계정으로 로그인한 Codex CLI가 필요합니다. PowerShell에서:

```powershell
Set-Location 'D:\program'
git clone https://github.com/seeyouworks/ai-subtitles.git
Set-Location '.\ai-subtitles'
.\install.bat
.\run.bat
```

NVIDIA GPU를 사용하려면 `install-gpu.bat`도 실행합니다. `run.bat`는 패키지가 설치되지 않은 경우 설치를 시도합니다. 모델은 첫 음성 인식 때 내려받습니다.

저장소에는 소스, 실행/설치 스크립트, 번역 원칙, 테스트와 공개 샘플의 출처·기준 대사를 포함합니다. 가상환경, 모델, 개인 설정, 캐시, 실제 영상과 로컬 검증 결과는 제외합니다. 샘플 영상과 보고서는 **무료 샘플 검증**을 실행하면 생성됩니다. `VALIDATION.md`의 과거 실행 경로는 작성자의 로컬 검증 자료이며 저장소에 동봉된 파일 경로를 뜻하지 않습니다.

## 실행

1. `run.bat`를 더블 클릭합니다. 영상 파일이나 폴더를 `run.bat`에 끌어 놓아도 됩니다.
2. **영상 선택** 또는 **폴더 선택**으로 파일을 추가합니다. **폴더 경로**에 경로를 직접 붙여 넣을 수도 있습니다.
3. 기본값인 원문 자동 감지, 한국어 번역, Whisper `turbo`, 장치 `auto`를 사용합니다.
4. 목록에 있는 파일은 **자막 생성**, 입력한 폴더 전체는 **폴더 자막 생성**을 누릅니다. 원문 자막만 필요하면 **Codex로 번역**을 해제합니다.

여러 영상을 순서대로 처리합니다. 이미 있는 SRT만 번역할 때는 **SRT 번역**을 사용합니다. 기존 결과는 기본적으로 덮어쓰지 않습니다.

**폴더 자막 생성**은 지정한 폴더의 영상으로 목록을 교체한 뒤 바로 처리합니다. **하위 폴더 포함**을 선택하면 아래 폴더도 검색하며, 자막은 각 영상이 있는 폴더에 저장합니다. 폴더의 기존 SRT/문서 파일은 입력 영상으로 가져오지 않습니다. 같은 이름의 `.srt`가 있으면 ‘기존 자막 있음’으로 건너뛰며, 다시 만들려면 **기존 결과 덮어쓰기**를 선택합니다. 영상 하나가 실패해도 다음 영상은 계속 처리합니다.

같은 폴더에 `영화.mp4`와 `영화.mkv`처럼 확장자만 다른 동명 영상이 있으면 두 자막의 이름이 충돌합니다. `영화.original.mp4`나 `영화.ko.mp4`가 다른 영상의 원문/번역 출력과 겹치는 경우도 검사합니다. 충돌한 영상을 ‘이름 중복’으로 표시하고 처리하지 않으므로 영상 이름을 구분하세요. 서로 다른 하위 폴더의 동명 영상은 각각 처리합니다.

## 생성 파일

입력이 `D:\Videos\영화.mp4`라면:

| 파일 | 내용 |
| --- | --- |
| `영화.srt` | 영상과 정확히 같은 이름의 재생용 자막. 번역을 켜면 선택 언어, 끄면 원문 |
| `영화.original.srt` | 추출 또는 음성 인식한 원문 |
| `영화.ko.srt` | 한국어 번역, 모든 구간의 처리가 성공한 경우 |
| `영화.ko.partial.srt` | 번역을 처리하지 못한 구간이 있는 경우. 해당 구간은 원문 유지 |
| `영화.subtitle-report.json` | 처리 방식, 사용한 언어, 확인 필요 구간 및 표시 길이 경고 |

번역 언어를 바꾸면 `ko` 대신 `en`, `ja`, `zh`, `es`, `ru` 등의 코드가 붙습니다. 자막 번호와 시간은 프로그램이 보존합니다. 이 프로그램은 SRT 생성용이며 영상 재인코딩이나 자막을 영상에 굽는 작업은 하지 않습니다.

`영화.srt`는 영상 처리에 성공한 경우에만 생성합니다. 번역 처리 불가 구간이 있으면 `.ko.partial.srt`와 보고서를 저장하며 새 재생용 자막은 만들지 않습니다. 이미 있는 재생용 자막은 그대로 보호합니다. 기존 SRT를 번역하는 작업에서는 입력 SRT를 재생용 출력으로 덮어쓰지 않습니다.

## 추출과 번역

- **내장 텍스트 자막 우선**: MKV/MP4 등에 SRT, ASS, SSA, WebVTT, mov_text 자막이 있으면 먼저 추출합니다. 원문 언어를 지정하면 그 언어로 표기된 트랙만 선택합니다. 자동 감지는 첫 번째 추출 가능한 텍스트 트랙을 사용합니다.
- 텍스트 자막이 없거나 추출에 실패하면 Whisper로 음성을 인식합니다. 화면에만 그려진 자막이나 PGS/VobSub 이미지 자막은 OCR하지 않고 음성 인식으로 처리합니다.
- 여러 오디오 트랙이 있는 영상은 **오디오 트랙**에서 원하는 트랙을 선택합니다. 번호는 첫 번째 `0`, 두 번째 `1`입니다.
- Whisper는 원문을 인식합니다. 한국어 이외의 영상을 한국어로 바꾸는 작업은 Codex가 담당합니다.
- **무음 필터(VAD)**는 기본적으로 해제되어 있습니다. 실제 영화 샘플에서 필터를 켜면 음악 위 대사가 누락되어 기본값을 바꿨습니다. 필터를 끄면 음악/효과음을 대사로 잘못 인식할 수도 있으므로 결과를 확인하세요. 말소리가 또렷한 강의나 인터뷰에서는 필터를 켜서 비교할 수 있습니다. 필터 변경 시 원문 캐시도 구분합니다.
- 영화로 제공한 자료는 작품 속 인물의 대사라는 맥락에서 번역합니다. 자극적인 발화를 사용자의 실제 의도나 행동 지시로 재해석하지 않습니다. 욕설이나 성적·폭력적 표현의 의미·말투·강도를 유지하고, 임의 순화, 별표 처리, 훈계, 경고문과 대사 창작을 금지합니다. 처리 불가 구간은 원문과 사유를 보존합니다. 상세 원칙은 `TRANSLATION_POLICY.md`와 프로젝트 `AGENTS.md`에 있으며 실제 Codex 요청에도 반영합니다. **모델의 모든 오역이나 순화를 완전히 검출하거나 방지한다고 보장하지 않습니다.**
- Codex에는 대사 텍스트와 앞뒤 문맥만 전달합니다. 영상/음성 파일은 전송하지 않습니다. 모델의 번역이 자연스러운지, 인식 결과가 맞는지는 짧은 샘플로 먼저 확인하세요.
- 성공한 번역 묶음은 프로젝트의 `cache`에 저장합니다. 중지나 통신 실패 후 같은 입력과 설정으로 재실행하면 이어서 처리합니다. 원문, 번역 언어, Codex 모델, 용어 지침이 바뀌면 해당 번역 캐시를 분리합니다. **덮어쓰기**는 결과 파일을 다시 쓰는 옵션이며 성공한 번역 캐시는 재사용합니다.

영화 대사 맥락을 명시한 번역 지침은 프롬프트 버전 2입니다. 이전 버전의 번역 캐시는 재사용하지 않으며 원문 캐시는 유지합니다. 기존 자막을 이 지침으로 다시 만들려면 **기존 결과 덮어쓰기**를 선택하세요.

## Codex 계정

현재 PC의 Codex CLI 로그인을 사용합니다. **Codex 로그인**을 누르거나 터미널에서 `codex login`을 실행해 ChatGPT 계정으로 로그인하세요. Pro 계정도 사용량 제한과 안전 정책을 적용받습니다. 번역 요청 전에 ChatGPT 로그인을 확인하며 API 키 로그인 상태에서는 요청하지 않습니다.

Codex 번역은 인터넷이 필요합니다. **Codex로 번역**을 해제하면 모델을 내려받은 뒤 음성 인식을 오프라인으로 실행할 수 있습니다.

번역 모델은 **GPT-6.1 Sol (`gpt-6.1-sol`)**을 기본값으로 명시합니다. 이 PC의 현재 Codex 설정과 모델 목록에서 확인한 모델이며, 실제 번역 요청에도 `codex exec --model gpt-6.1-sol`을 전달합니다. 기존의 공란 설정도 이 값으로 바꿉니다. 다른 모델을 원하면 **Codex 모델** 또는 `--codex-model`에 계정에서 사용 가능한 모델명을 입력하세요. 모델을 사용할 수 없으면 오류를 보고하며 다른 모델로 바꾸지 않습니다.

번역 실행에서는 사용자 설정 파일 전체를 불러오지 않습니다. 앞으로 Codex 앱의 선택 모델을 바꾸더라도 이 프로그램의 모델 설정은 자동으로 바뀌지 않으므로 위 입력란에서 변경하세요. [공식 모델 선택 문서](https://learn.chatgpt.com/docs/models)에서 CLI 모델 지정 방법을 확인할 수 있습니다.

프로그램 로그에 요청 모델과 CLI가 확인해 준 실제 모델을 표시하고, 영상별 JSON 보고서의 `codex` 항목에 기록합니다. `requested_model`은 지정한 모델, `actual_model`은 CLI 출력에서 확인한 모델, `model_confirmed`는 두 값의 일치 여부입니다. 실제 모델명 출력이 없으면 확인되지 않은 상태로 기록합니다. 번역 캐시는 명시한 모델별로 구분하며, 같은 모델의 완료한 번역을 재사용할 때 모델 확인 기록도 유지합니다.

## 설치 / 모델

- Python 3.10 이상과 Tcl/Tk가 필요합니다. `install.bat`는 이 폴더의 `.venv`에 패키지를 설치합니다.
- FFmpeg는 imageio-ffmpeg 패키지에 포함됩니다. 시스템 FFmpeg를 별도로 설치하지 않아도 됩니다.
- `turbo`는 다국어 `large-v3-turbo` 모델입니다. 다른 모델은 첫 사용 때 프로젝트 `models`에 내려받습니다. `large-v3`는 정확도 우선, `small`/`base`/`tiny`는 속도와 용량 우선입니다. 다운로드 중에는 중지 요청이 즉시 반영되지 않을 수 있습니다.
- GPU는 CUDA 12용 cuBLAS와 cuDNN 9가 필요합니다. `install-gpu.bat`는 NVIDIA Windows 런타임을 **이 프로젝트 가상환경**에 설치합니다. 시스템 CUDA 설정은 변경하지 않습니다. NVIDIA 드라이버는 별도로 필요합니다.
- `auto`는 NVIDIA GPU를 우선하고 실행에 실패하면 CPU로 전환합니다. `cuda`는 GPU 실행을 강제하므로 라이브러리에 문제가 있으면 오류를 보고합니다. `cpu`는 CPU만 사용합니다.
- 임시 WAV는 처리 후 삭제됩니다. 모델, 원문 캐시와 번역 진행 기록은 프로그램 폴더에 남습니다. 디스크 공간은 영상 길이와 모델에 따라 필요합니다.

## 명령줄

PowerShell에서:

```powershell
Set-Location 'D:\program\ai-subtitles'
& '.\.venv\Scripts\python.exe' app.py --cli 'D:\Videos\영화.mp4'
& '.\.venv\Scripts\python.exe' app.py --cli 'D:\Videos' --target ko
& '.\.venv\Scripts\python.exe' app.py --cli 'D:\Videos' --recursive --target ko
& '.\.venv\Scripts\python.exe' app.py --cli 'D:\Videos\원문.srt' --source en
& '.\.venv\Scripts\python.exe' app.py --cli 'D:\Videos\영화.mp4' --original-only --force-whisper
& '.\.venv\Scripts\python.exe' app.py --check
& '.\.venv\Scripts\python.exe' app.py --verify --device cuda
& '.\.venv\Scripts\python.exe' app.py --verify --original-only
& '.\.venv\Scripts\python.exe' app.py --download-sample
```

`--recursive`, `--overwrite`, `--model large-v3`, `--device cpu`, `--audio-track 1`, `--speech-filter`, `--codex-model 모델이름`, `--glossary 'John=존'` 등을 지정할 수 있습니다. 일반 처리 CLI의 종료 코드 `1`은 실패 또는 확인 필요 구간이 있음을 뜻합니다. 기존 재생용 자막이 있어서 건너뛴 경우는 실패로 집계하지 않습니다. CLI JSON의 `subtitle`은 영상과 같은 이름의 자막 경로이며, 각 영상 JSON 보고서에는 `matched_subtitle`로 기록합니다. CLI 설정은 GUI 저장 설정과 별도로 적용합니다.

## 무료 영상으로 검증

GUI의 **무료 샘플 검증** 또는 `verify.bat`를 실행합니다. 영상 파일을 직접 준비할 필요가 없습니다. 공식 서버의 **Sintel 예고편**(52.21초, 4.17 MiB, 영어)을 내려받아 실제 음성 인식과 한국어 번역을 수행합니다. 영상은 [CC BY 3.0](https://durian.blender.org/sharing/)이며 제작자 표기를 보관합니다.

검증에서는 원문 영어, 번역 한국어, 첫 번째 오디오 트랙을 사용합니다. 화면에서 선택한 Whisper 모델, 장치, 무음 필터, Codex 모델과 번역 여부를 적용합니다. **Codex로 번역**을 해제하거나 `--original-only`를 붙이면 원문 인식만 검사합니다. 기본 검증은 실제 번역과 별도 의미 검토로 Codex를 두 번 호출하여 계정 사용량을 소비합니다.

다음 항목을 검사합니다.

- 다운로드 파일의 크기와 SHA-256, 영상/오디오 전체 프레임 읽기
- 프로그램 자동 테스트, 자막 번호·시간·빈 내용
- 모델 출력과 별도로 준비한 기준 대사 네 구간의 누락, 영어 단어 오류율(WER)
- 기준 구간 밖에서 인식한 추가 대사, 번역 번호·시간 보존 및 한국어 누락
- 번역 처리 불가 여부와 기준 대사에 대한 Codex의 의미 검토

다운로드는 `test_media`에 보관하고 재사용 전에도 해시를 확인합니다. 각 검증은 `test_runs/날짜-고유번호`에 새 영상 경로와 결과를 만들어 **이전 인식·번역 캐시로 검사를 건너뛰지 않습니다**. GUI의 **검증 보고서**에서 최신 HTML을 엽니다. 영상 재생, 원문/한국어 대조, 검사 결과와 SRT 링크가 있습니다. JSON 보고서도 같은 폴더에 남습니다.

결과는 **통과 / 주의 / 실패**로 구분합니다. 대사 누락, 허용 상한 20%를 넘은 WER, 구조 문제, 번역 실패는 ‘실패’입니다. 기준에 없는 추가 대사 의심은 ‘주의’입니다. `--verify`와 `verify.bat`의 종료 코드는 통과 `0`, 실패 `1`, 주의 `2`입니다. 원문만 검사하면 번역 항목은 생략으로 표시합니다.

WER는 이 영어 샘플의 단어 오류율이며 전체 영화나 번역의 정확도를 뜻하지 않습니다. Codex의 의미 검토는 같은 제공자 모델을 쓰는 보조 검사입니다. 다른 언어, 장편 영화, 성인 대사 품질을 이 샘플 하나로 보장하지 않습니다. 출처와 기준 대사는 `test_data/ATTRIBUTION.md`에 있습니다.

## 실패와 재실행

- 자막은 같은 폴더의 임시 파일에 끝까지 기록한 뒤 공개합니다. 저장 실패로 비어 있거나 일부만 기록된 최종 자막이 생기지 않도록 했습니다. 기본 설정에서는 기존 자막을 보호하고, 내용이 동일하면 저장을 재사용합니다.
- 같은 자막/보고서를 생성하는 다른 프로그램 실행은 오류로 중지합니다. 잠금은 운영체제가 관리하며 프로그램을 강제로 종료해도 해제됩니다. `cache/locks`의 작은 파일이 남아 있어도 계속 잠긴 상태를 뜻하지 않습니다.
- 영상과 함께 선택한 SRT 입력도 이름 충돌 검사에 포함합니다. 덮어쓰기를 선택해도 다른 입력 파일을 출력으로 바꾸는 일은 차단합니다.
- 손상된 원문 캐시는 입력에서 다시 추출합니다. 손상된 번역 기록은 잘못된 항목만 다시 번역하고 정상 완료한 항목은 재사용합니다. 번역은 끝났지만 영상 이름의 SRT 저장만 실패한 경우에도 기존 번역 캐시와 동일한 결과를 재사용하여 복구할 수 있습니다.
- 처리 중 입력의 크기 또는 수정 시각이 바뀌면 완료 결과 저장을 중지합니다. 입력을 편집하거나 교체했다면 다시 실행하세요.
- 번역 실패·저장 실패·중지는 로그와 저장 가능한 보고서에 기록합니다. 덮어쓰기 실행의 새 번역이 부분 결과가 되면 이전 완성 자막을 보관하고 보고서의 `retained_outputs`로 표시합니다. 재생 프로그램이 이전 자막을 사용할 수 있으므로 보고서를 확인하고 재처리 시 덮어쓰기 옵션을 선택하세요.

각 파일은 개별적으로 저장합니다. 원문·번역·재생용 SRT·보고서 전체를 한 번에 교체하는 트랜잭션은 제공하지 않습니다. 디스크나 권한 문제로 보고서 자체를 저장하지 못하면 화면/CLI 오류를 확인하세요. 오디오 및 내장 자막 추출의 임시 폴더는 프로젝트 `work` 아래에서 관리하며 정상 종료와 처리 오류 시 정리합니다. 강제 종료 후 남은 임시 파일은 자동으로 일괄 삭제하지 않습니다.
